# pocketboard (포켓보드)

**폰에 손글씨를 쓰면 PC에 글자가 들어가는 블루투스 키보드 앱**

화면을 보지 않고 폰에 쓱쓱 쓰고, 두 번 톡 치면 PC에 입력돼요.<br>
한글과 영어를 섞어 써도 한/영 키를 누를 필요가 없어요.

### [최신 릴리즈 (APK)](https://github.com/ouor/pocket-board/releases/latest)

</div>

> [!NOTE]
> **PC에는 아무것도 설치하지 않아요.** 폰이 블루투스 키보드로 PC에 연결돼요. <br/>
> 지금은 **Windows PC** 기준으로 만들고 확인했어요. 다른 기기도 블루투스 키보드로 연결은 되지만 동작을 보장하지 않아요.

## 📸 이렇게 써요

1. **PC와 연결하기**: 앱의 안내대로 Windows 설정 → 블루투스 및 장치 → 장치 추가에서 폰을 골라요. 처음 한 번만 하면 다음부터는 마지막 PC에 알아서 다시 연결돼요.
2. **쓰기**: **쓰기 시작**을 누르면 화면이 까맣게 바뀌어요. 그 위에 손가락으로 글씨를 써요. 한 자리에 겹쳐 써도, 옆으로 이어 써도 돼요.
3. **보내기**: 한 손가락으로 **두 번 톡** 치면 쓴 글씨가 PC에 입력돼요. 쓴 글씨가 없을 때 두 번 톡 치면 엔터예요.

## ✨ 할 수 있는 것

- **손글씨 → 키보드 입력**: 폰이 블루투스 키보드가 돼요. PC에 프로그램을 깔 필요가 없어요.
- **한영 섞어 쓰기**: "slack에 OK 남김"처럼 섞어 쓰면 한/영 전환 없이 그대로 들어가요. 영어는 PC의 한/영 상태와 상관없이 입력돼요.
- **겹쳐 쓰기와 이어 쓰기**: 모드를 고르지 않아도 한 자리에 겹쳐 쓴 글씨와 옆으로 이어 쓴 글씨를 모두 알아봐요.
- **화면을 안 봐도 되게**: 쓰는 동안 화면은 완전히 까맣고, 결과는 진동으로 알려 줘요. 소리는 나지 않아요.
- **제스처로 편집**: 기본 제스처는 아래와 같고, 설정에서 동작마다 다른 제스처로 바꿀 수 있어요.

  | 제스처 | 동작 |
  |---|---|
  | 한 손가락 두 번 톡 | 보내기 (쓴 글씨가 없으면 엔터) |
  | 두 손가락 왼쪽으로 밀기 | 한 글자 지우기 (보내기 전이면 마지막 획만) |
  | 두 손가락 톡 | 띄어쓰기 |
  | 두 손가락 위로 밀기 | 덩어리 지우기 (방금 보낸 만큼 지우기) |
  | 세 손가락 톡 | 한/영 맞추기 |

- **엔터 실수 막기**: 빈 화면 두 번 톡 = 엔터를 끄고, 엔터를 네 번 톡 같은 다른 제스처에 따로 둘 수 있어요.
- **폰 안에서 인식**: 글씨 인식은 Google ML Kit으로 폰 안에서 해요. 처음 한 번 인식 모델을 받으면 인터넷 없이 써요.
- **여러 PC**: 연결한 PC 목록에서 골라 연결하고, 이름을 바꾸거나 지울 수 있어요.
- **빠른 설정 타일**: 알림창의 타일을 누르면 바로 쓰기 화면이 열려요.
- **배터리 아끼기**: 안 쓰면 연결을 끊어요. 10분, 30분(기본), 1시간, 끊지 않음 중에 골라요.
- **진동 조절**: 진동 끄기, 세기(약·중·강)를 설정에서 바꿔요.
- **어두운 미리보기**: 켜면 쓰는 동안 인식 결과를 아주 어둡게 보여 줘요. 기본은 꺼져 있어요.
- **연습하기와 튜토리얼**: PC로 보내지 않고 인식을 시험하거나, 튜토리얼을 다시 볼 수 있어요.

### 이럴 때 써 보세요

- 침대에서 이불 덮고 누워, 키보드 없이 PC에 몇 마디 입력하고 싶을 때
- 음성 입력처럼 소리를 내기 곤란한 곳에서
- 키보드 자판을 보고 정확히 누르기 힘들 때

## ⬇️ 설치하기

1. [최신 릴리즈](https://github.com/ouor/pocket-board/releases/latest)에서 `.apk` 파일을 받아요.
2. 받은 파일을 열어요. "출처를 알 수 없는 앱" 안내가 나오면 **설정**을 눌러 이 출처(브라우저나 내 파일)를 허용해요.
3. Play 프로텍트 경고가 뜨면 **세부정보 더보기 → 무시하고 설치**를 눌러요. Play 스토어를 거치지 않은 앱이라 뜨는 안내예요.
4. 앱을 열면 권한, 인식 모델 받기(약 40MB), PC 연결, 튜토리얼 순서로 안내해요.

**업데이트**는 새 버전 APK를 그대로 설치하면 돼요. 설정, 제스처, 연결한 PC 목록은 그대로 남아요.

> [!WARNING]
> 소스에서 직접 빌드한 개발용 APK를 설치해 둔 적이 있다면, 서명 키가 달라서 릴리즈 APK가 업데이트로 설치되지 않아요. 앱을 지우고 새로 설치해 주세요.

이 저장소의 [릴리즈](https://github.com/ouor/pocket-board/releases)에서 받은 APK만 설치해 주세요. 정식 APK의 서명 인증서 SHA-256 지문은 아래와 같아요.

```
88:ED:DB:48:DC:77:E0:D9:D7:F0:F4:5C:F8:BD:AC:E4:25:DC:44:06:A2:30:9D:60:F8:29:D6:9E:01:8F:12:F5
```

PC에서 `apksigner verify --print-certs pocket-board-*.apk`로 확인할 수 있어요.

### 필요한 것

- Android 9 이상, 64비트(arm64) 휴대폰
- 블루투스 키보드(HID) 기능을 지원하는 휴대폰. 앱이 처음 열릴 때 확인하고, 지원하지 않으면 알려 줘요.
- Google Play 서비스. 글씨 인식에 필요해요.
- 블루투스가 있는 Windows PC와, 한글을 쓰려면 PC에 **Microsoft 한국어 입력기**
- 앱 화면은 한국어로 나와요.

## 🔒 개인정보

- **쓴 글씨와 입력한 글자는 어디로도 보내지 않아요.** 인식은 폰 안에서 하고, 결과는 블루투스로 PC에만 들어가요.
- 인식 도구(Google ML Kit)의 사용 통계는 Google로 가요. 앱에서 끌 수 없지만, 쓴 내용은 들어가지 않아요.
- 인터넷은 인식 모델 받기(처음 한 번)와 위 사용 통계에만 써요.
- 설정, 제스처, 연결한 PC 목록은 폰에만 남아요.
- 따로 허락을 받는 권한은 **블루투스 연결**(주변 기기)과 **알림**이에요. 알림은 연결 중임을 보여 주는 상주 알림에 쓰고, 허락하지 않아도 연결은 동작해요. 위치, 카메라, 연락처, 저장소 권한은 쓰지 않아요.
- 광고, 가입, 계정이 없어요.

## 🙋 자주 묻는 질문

| 이럴 때 | 이렇게 해 보세요 |
|---|---|
| 설치가 안 돼요 | "출처를 알 수 없는 앱" 허용을 확인해 주세요. Android 9 미만이나 32비트 휴대폰에서는 설치되지 않아요. |
| PC 목록에 폰이 안 보여요 | 앱의 PC 연결 화면을 열어 둔 채로 PC에서 장치 추가를 해 주세요. 폰에 "검색 허용" 창이 뜨면 허용해야 보여요. |
| 한글이 영어나 깨진 글자로 들어가요 | PC에 한국어 입력기가 있는지 확인하고, **세 손가락 톡**(한/영 맞추기)을 해 보세요. 설정 → 연결 문제 해결에 증상별 안내가 있어요. |
| 아무것도 입력되지 않아요 | PC에서 글자를 넣을 곳을 눌러 커서를 둬 주세요. 그래도 안 되면 설정 → 연결 테스트로 확인해요. |
| 엔터가 자꾸 잘못 들어가요 | 설정 → 제스처에서 엔터를 네 번 톡에 두고, "쓴 글씨 없을 때 … = 엔터"를 꺼 보세요. |
| 쓰기 화면에서 어떻게 나가요? | 화면 가장자리에서 뒤로 가기를 두 번 해요. 연결은 알림의 **연결 끊기**로 끊을 수 있어요. |
| 진동 때문에 옆 사람이 깰까 걱정돼요 | 설정 → 진동을 끄거나 세기를 약으로 바꿔요. |

문제가 계속되면 [이슈](https://github.com/ouor/pocket-board/issues)에 휴대폰 기종, PC의 Windows 버전과 함께 남겨 주세요.

## 🛠️ 개발자 노트

여기부터는 앱을 직접 빌드하거나 고치려는 분을 위한 내용이에요.

- 빌드: Android Studio에서 열거나 `./gradlew assembleDebug`. 테스트는 `./gradlew :app:testDebugUnitTest`.
- 릴리즈 빌드: `./gradlew assembleRelease`는 arm64-v8a 전용 APK를 만들어요(`app/build/outputs/apk/release/`). 서명 키(`signing/keystore.properties`)가 없으면 서명 없는 APK가 나와요. 서명 방법은 [signing/SIGNING.md](signing/SIGNING.md)를 봐 주세요. 키 파일은 저장소에 없어요.
- 문서
  - 컨셉과 결정: [docs/concept.md](docs/concept.md), [docs/decisions.md](docs/decisions.md)
  - 기획: [docs/planning/prd.md](docs/planning/prd.md)
  - 구조: [docs/architecture/architecture.md](docs/architecture/architecture.md), [docs/architecture/integration.md](docs/architecture/integration.md)
  - 모듈 명세: [hid](docs/core/hid.md) · [keymap](docs/core/keymap.md) · [ink](docs/core/ink.md) · [gesture](docs/core/gesture.md)
- 모듈
  - `:core:hid`: 블루투스 HID 키보드 등록, 페어링, 재연결
  - `:core:keymap`: 글자 → 키 입력 변환(두벌식, 한/영 상태 추적)
  - `:core:ink`: 겹쳐 쓴 글씨 나누기와 손글씨 인식
  - `:core:gesture`: 탭·스와이프 판정과 제스처 매핑
- 쓰인 기술
  - 앱: Kotlin, Jetpack Compose (Material 3)
  - 인식: Google ML Kit Digital Ink Recognition (온디바이스)
  - 연결: Android `BluetoothHidDevice`
  - 저장: DataStore
- 설정의 **버전**을 일곱 번 누르면 숨은 개발자 옵션(접촉 기록, 한/영 입력 방식, 인식·제스처 판정 값)이 열려요.
